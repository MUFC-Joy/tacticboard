# 看球战术台 TacticBoard

一个为足球战术小白设计的**互动战术学习台**，纯前端单页应用，无任何依赖，打开即用。

> 数据截至 2026 年 10 月（2026-27 赛季）：卡里克执教曼联、齐达内执教法国、克洛普执教德国、恩佐 1.25 亿镑转会曼城、罗德里加盟巴萨……

## 功能模块

| 模块 | 内容 |
|---|---|
| 📐 阵型 | 10 种阵型（4-2-3-1 / 4-3-3 / 3-4-2-1 / 现代通用形状 2-3-5 等）带球场图、优劣势、克制关系 |
| 🎭 角色 | 6/8/10 号位、伪9、翼卫、边后腰、肋部8号等角色详解，每条配可点击的现役球员例子 |
| 🏟️ 球队 | 五大联赛豪门 DNA（曼联/拜仁深度卡）+ 英超 20 队侦察报告（对曼联的威胁点）+ 世界前 15 国家队 |
| 🔍 球员 | 250+ 名球员百科：风格详解、惯用脚、俱乐部、国家队、搭档关系；支持中英文/别名搜索与组合筛选（如"左脚中卫"）；**曼联专属**板块：26 人技术画像 × 三种阵型职责 + 13 组搭档组合解析 + 换帅预案 |
| 🎮 模拟器 | 阵容实验室：点选换人、6 种阵型、自动排阵；**警告引擎**（位置本能 / 惯用脚 / 属性门槛 / 全局平衡 / 中场·防线·锋线组合诊断）；**对手简报**随阵型与首发实时计算危险度 |
| 📖 词典 | 28 条战术名词 + "为什么"专栏（谁保护弧顶 / 中卫为何易伤 / 三中卫的代价）；54 题战术测验：随机抽题、避开近期做过的题、学习进度存 localStorage |

## 使用方法

**零依赖，两种打开方式：**

1. 直接双击 `index.html`（纯前端，`file://` 也能跑）
2. 或起一个本地服务：

```bash
python3 -m http.server 8899
# 访问 http://127.0.0.1:8899
```

手机上：把整个文件夹存到「文件」App（iOS）点开 `index.html` 即可离线使用。

## 文件结构

```
tactics/
├── index.html   # 全部界面逻辑（约 900 行，无框架）
├── data.js      # 内容数据：阵型/角色/球队/国家队/词典/题库/曼联专属解析
├── players.js   # 球员数据库：250+ 人，曼联全队带属性数值（阵容引擎用）
└── README.md
```

## 数据更新机制

内容与逻辑分离（`data.js` / `players.js`）——转会窗、换帅后只需更新数据文件，程序不用动。球员信息以官方名单为准，发现过期信息改对应条目即可。

## 已知边界

- 球员属性数值是**教学示意值**（教判断逻辑，非真实球探数据）
- 少数球员公开资料有限，标注"随赛季补充"
- 学习记录（测验历史）存在浏览器 localStorage，清缓存会丢
